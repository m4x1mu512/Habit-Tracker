# Динамическая настройка строки состояния (Status Bar) для светлой и темной тем

Обеспечение идеальной читаемости и контраста системной строки состояния (часы, индикаторы батареи, сети и уведомлений) с автоматическим переключением: черные иконки на светлом фоне в светлой теме и белые иконки на темном фоне в темной теме при прозрачном фоне строки состояния.

## User Review & Critical Decisions

> [!IMPORTANT]
> Подтвержденные параметры оформления строки состояния:
> - **Цвет иконок и часов**: Темные/черные элементы в светлой теме (`isAppearanceLightStatusBars = true`), светлые/белые элементы в темной теме (`isAppearanceLightStatusBars = false`).
> - **Фон статус-бара**: Полностью прозрачный фон (Edge-to-Edge) для бесшовного слияния с заголовком и общим фоном приложения.
> - **Навигационная панель (Navigation Bar)**: Соответствующая адаптация системных кнопок/полосы жестов внизу экрана для гармоничного визуального стиля.

---

## 1. Overview & Core Concept

- **Что делает**: Синхронизирует системные контроллеры окна Android (`WindowInsetsControllerCompat`) с текущей темой приложения (Светлая, Темная или Системная).
- **Пользовательская ценность**: Исключает ситуацию, когда белые иконки отображаются на светлом фоне экрана (становясь невидимыми) или темные иконки на темном фоне. Статус-бар всегда сохраняет максимальную контрастность и четкость на любых версиях Android (начиная с Android 6+ и Android 8+).

---

## 2. User Experience & Visual Design

### Поведение интерфейса
1. **Светлая тема (Light Mode)**:
   - Фон экрана: мягкий светлый `#F8F9FA` / `#FFFFFF`.
   - Фон статус-бара: Прозрачный (`Color.Transparent`).
   - Иконки статус-бара (время, уровень заряда батареи, Wi-Fi, мобильная сеть): Насыщенный темный/черный цвет для 100% читаемости.
   - Системная панель навигации (снизу): Прозрачная со светлым фоном и темными иконками жестов/кнопок.
2. **Темная тема (Dark Mode)**:
   - Фон экрана: глубокий темный `#121212` / `#1E1E1E`.
   - Фон статус-бара: Прозрачный (`Color.Transparent`).
   - Иконки статус-бара: Чистый белый цвет для безупречного контраста.
   - Системная панель навигации (снизу): Прозрачная с белыми иконками навигации.
3. **Системный режим (System Default)**:
   - Автоматически следует за глобальной системной темой Android и обновляется в реальном времени при переключении режима в шторке быстрых настроек.

## 3. Key Product Decisions & Trade-Offs

- **Решение 1: Интеграция в Composable-тему (`MyApplicationTheme`) через `SideEffect` и `WindowCompat`**:
  - *Выбранный подход*: Использование `LocalView.current` и `WindowCompat.getInsetsController(window, view)` внутри `SideEffect` в `Theme.kt`.
  - *Почему*: Это гарантирует, что статус-бар мгновенно обновляется при смене темы как в настройках приложения (переключатель тем), так и при изменении системной темы, без перезапуска `Activity`.
  - *Альтернативы*: Вызов `enableEdgeToEdge()` только в `MainActivity.onCreate()` не реагирует на переключение `themeMode` внутри `ViewModel` во время работы приложения.
- **Решение 2: Прозрачные системные панели с сохранением системных отступов (`WindowInsets`)**:
  - *Выбранный подход*: Статус-бар и навигационная панель остаются прозрачными (`statusBarColor = Color.TRANSPARENT`), а контент экрана защищен внутренними отступами Material 3 `Scaffold` (`contentWindowInsets`).
  - *Почему*: Обеспечивает современный безрамочный вид (Edge-to-Edge) без наложения текста или кнопок на системные индикаторы.

## 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────┐
│                   HabitViewModel                       │
│             StateFlow<ThemeMode> (SYSTEM/LIGHT/DARK)   │
└──────────────────────────┬─────────────────────────────┘
                           │ collectAsState()
                           ▼
┌────────────────────────────────────────────────────────┐
│                  MyApplicationTheme                    │
│      Вычисление: darkTheme = isDark(themeMode)         │
└──────────────────────────┬─────────────────────────────┘
                           │ SideEffect
                           ▼
┌────────────────────────────────────────────────────────┐
│             WindowCompat.getInsetsController           │
│  - isAppearanceLightStatusBars = !darkTheme            │
│    (true: черные часы/иконки; false: белые часы/иконки)│
│  - isAppearanceLightNavigationBars = !darkTheme        │
│  - statusBarColor = Transparent                        │
│  - navigationBarColor = Transparent                    │
└────────────────────────────────────────────────────────┘
```

### План изменений:
1. **Обновление `Theme.kt`**:
   - Внедрение `SideEffect` с `LocalView.current` и получением `Activity.window`.
   - Настройка `insetsController.isAppearanceLightStatusBars = !darkTheme`.
   - Настройка `insetsController.isAppearanceLightNavigationBars = !darkTheme`.
   - Установка прозрачного цвета системных баров через `window.statusBarColor` и `window.navigationBarColor`.
2. **Проверка `MainActivity.kt`**:
   - Обеспечение бесшовного взаимодействия с `enableEdgeToEdge()` и отсутствия конфликтующих установок цветов.
3. **Компиляция и верификация**:
   - Запуск `compile_applet` для подтверждения успешной сборки и отсутствия ошибок типов.
